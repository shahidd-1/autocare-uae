# AUTOCARE UAE — Premium Frontend Mock

A one-page, dark-futuristic car-care landing page for a UAE client demo.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Build for Vercel

```bash
npm run build
```

The project is frontend-only. Prices, testimonials and service-area details are placeholders and should be replaced with verified client information before launch.
